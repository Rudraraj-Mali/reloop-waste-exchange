ACID Transaction with Row Locking

When a Generator accepts an exchange request, the backend executes a serialized transaction with WITH (UPDLOCK, ROWLOCK) on the WasteListings row. This atomically marks the listing "Accepted" and rejects all competing pending requests — preventing double-booking race conditions.

AFTER UPDATE Trigger on ExchangeRequests

Trigger trg_ExchangeRequests_Completed fires automatically when a request status becomes "Completed". It updates WasteListings.status to "Completed" and awards +10 eco_points to the Generator — all without any application-level code.
