DBMS Concept: ACID Concurrency Control with Row Locking

When you click Accept (ACID) below, the application initiates an atomic transaction with WITH (UPDLOCK, ROWLOCK) on the WasteListings row in Azure SQL. This guarantees Isolation by preventing race conditions, marks the listing as 'Accepted', and automatically marks all competing pending requests as 'Rejected' in one atomic commit.

DBMS Concept: SQL AFTER UPDATE Trigger

When you collect materials and click Mark Completed (Trigger), an UPDATE is issued on ExchangeRequests. The Azure SQL Database Trigger (trg_ExchangeRequests_Completed) executes automatically to:
1. Update the corresponding WasteListings row to 'Completed'.
2. Automatically award +10 Eco Points to the Generator in the Users table.
